# Changelog

All notable changes to MemsSuite are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.0.3] - 2026-11-17

### Added

- Start a new diagnostic session without restarting the application.
- Use a native save dialog when downloading ECU logs.

## [0.0.2] - 2026-10-24

### Added

- Renamed the application from WebMemsFCR to MemsSuite.
- Added the Tauri desktop runtime and native serial transport foundation.

## [0.0.1] - 2026-10-24

### Added

- Added circuit and sensor status gauges to the live dashboard.
